# Hermes Encrypted Drive — public documentation

Static application information and privacy policy for an owner-operated rclone crypt setup. This repository is documentation only: it contains no storage credentials, encryption keys, OAuth configuration, or access to Google Drive.

## Pages

- `index.html`: application homepage
- `privacy.html`: privacy policy
- `styles.css`: local stylesheet
- `.nojekyll`: serve the static files without Jekyll processing

The documentation has no JavaScript, forms, analytics integrations, or third-party font dependencies. Publishing it does not publish the storage service or its data.

Application contact: kyoungrok.openclaw@gmail.com

Personal-use configuration; not an official Google, rclone, or Nous Research product.
