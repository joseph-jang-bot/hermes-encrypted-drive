Privacy policy

Effective date: November 12, 2026

Hermes Encrypted Drive is a personal-use storage utility operated by the owner of the connected Google account. This policy describes that configured utility and this documentation website.

1. Data accessed and purpose

The application uses Google's drive.file permission to create, read, update and delete files and folders created by the application or specifically authorized for it. It processes their contents and metadata, such as names, identifiers, sizes and modification times, to provide encrypted upload, download, listing and file management.

It uses OAuth access and refresh tokens to maintain the Google Drive connection. It does not request Gmail or Calendar access, the account's password, or unrestricted access to every file in Drive.

2. Encryption and storage

The configured rclone crypt layer encrypts file contents and file and folder names locally before transfer to Google Drive. The owner holds the encryption keys; the keys are not uploaded to Google Drive as part of this storage configuration. Encryption recovery material is stored separately in the owner's 1Password vault.

Google stores the encrypted objects and may process associated metadata, including sizes, counts, timestamps and access activity. Encryption does not conceal all metadata.

The owner's computer can hold decrypted files and a decrypted filesystem cache. OAuth credentials are stored in locally permission-restricted configuration files. Local applications running with sufficient permissions can access decrypted data. This utility is not a guarantee against compromise of the owner's computer or account.

Encryption applies to transfers through the configured encrypted storage path, not to unrelated uploads made using Google's website or other clients.

3. Use and disclosure

Google user data is used to provide and maintain the requested personal storage functionality. The application does not sell Google user data, use it for advertising, or transfer it to data brokers. The configured storage operation does not send file contents to AI model providers or use them to train models.

Google receives the encrypted storage objects and the information needed to operate its API. 1Password stores the owner's separately configured encryption recovery material. Any sharing or processing the owner independently initiates through other applications is outside this storage utility.

Hermes Encrypted Drive's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

4. Retention and deletion

Encrypted files remain in Google Drive until the owner deletes them. Deleted objects may remain in Drive's trash until permanently removed under Google's retention behavior. Independent backups are retained according to the owner's choices.

Local cache retention depends on cache settings and pending transfers. Open or not-yet-uploaded files can remain cached longer than the configured target. Do not delete a cache containing pending uploads.

To remove the application and its data, the owner can stop the mount, complete or cancel pending transfers, revoke Google access, delete the app-managed Drive files and empty the relevant trash, then remove local credentials, decrypted copies and caches and any unwanted recovery backups. These are separate actions; revoking access alone does not delete stored files.

5. Control and revocation

The owner can revoke the application's access through Google Account third-party connections. Revocation prevents future authorized API access once existing credentials cease to be valid; it does not erase previously stored data.

Keep encryption recovery material until all retained encrypted data is no longer needed. Losing the keys can make the encrypted files unrecoverable.

6. This documentation website

The website contains static documentation only. It has no sign-in, upload forms, embedded tracking scripts, added analytics, or application cookies. It does not receive Google OAuth tokens or access Drive files.

The site is intended for hosting on GitHub Pages. GitHub may collect standard technical information from visitors, including IP addresses and request logs, under the GitHub General Privacy Statement.

7. Contact and changes

For questions about this application, privacy, access or deletion, contact the operator at kyoungrok.openclaw@gmail.com. Correspondence is used to respond to the request and may be retained in the operator's email account.

Material changes to this policy will be reflected on this page with an updated effective date.
