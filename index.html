Your Google Drive.

Hermes Encrypted Drive uses rclone crypt to encrypt file contents and file and folder names on the owner's computer before uploading them to Google Drive.

This is a private-use, owner-operated configuration, not a public storage service. This website provides application information and a privacy policy. It does not connect to your Drive, accept uploads, or ask for Google credentials.

What the application does

A local filesystem mount lets the owner read and write decrypted files while the configured Google Drive storage receives encrypted data and encrypted names. Downloads are decrypted locally using the owner's encryption keys.

Encryption protects file contents and names within this configured mount. It does not hide all metadata: Google can still observe information such as object counts, sizes, timestamps and access activity. Files uploaded directly through other applications are not automatically encrypted by this utility.

Google access requested

The application requests https://www.googleapis.com/auth/drive.file to create and manage its encrypted storage and to access files specifically authorized for it. It does not request access to Gmail, Calendar, or the entire contents of the owner's Drive.

Google authorization takes place separately through the owner's installed application. There is no authorization or sign-in flow on this website.
